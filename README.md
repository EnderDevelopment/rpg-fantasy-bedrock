# RPG Fantasy Bedrock

RPG Fantasy Bedrock is a complex Minecraft Bedrock Edition plugin that enhances the game with RPG elements. It includes custom classes, skills, quests, and a persistent player data system. The plugin is designed to work with Minecraft Bedrock Edition version 26.0 and provides a rich, immersive RPG experience.

## Install

1. Download the plugin from the [GitHub releases page](https://github.com/yourusername/RPGFantasyBedrock/releases).
2. Place the downloaded `.jar` file into the `plugins` folder of your Minecraft Bedrock server.
3. Start or restart your Minecraft Bedrock server.

## Use

1. Join a Minecraft Bedrock server with the RPG Fantasy Bedrock plugin installed.
2. Use the `/ciao` command to greet the server.
3. Explore the custom RPG features, including classes, skills, and quests.
